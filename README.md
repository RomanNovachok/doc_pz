Для першого завдання на діаграмі використання [use case] слід визначити та представити основних акторів.

При створенні діаграми класів слід використовувати можливості ООП: класи, успадкування, поліморфізм, інкапсуляцію. Примітка — зазвичай діаграма класів служить для представлення статичної структури моделі системи в цілому, однак для цілей цієї лабораторної роботи намалюйте лише ту її частину, яка стосується поставленої задачі.

Аmazon

Опишіть варіант(и) використання [use case] для додавання нового продавця і товару на платформі Amazon. Варіант(и) використання мають містити опис всіх необхідних компонентів варіанту використання, зокрема, основний порядок дій та альтернативні шляхи, винятки.

Намалюйте діаграму класів [class diagram], щоб представити множину категорій товарів та конкретних товарів, та інші класи, які необхідні для реалізації сценарію купівлі товару покупцем. Примітка - зазвичай діаграма класів служить для представлення статичної структури моделі системи в цілому, однак для цілей цієї лабораторної роботи намалюйте лише ту її частину, яка стосується поставленої задачі

Намалюйте діаграму активності [activity diagram] купівлі товару покупцем: із моменту входу на сайт до моменту доставки товару

Намалюйте діаграму послідовності [sequence diagram], яка показує додавання товару в корзину покупцем. При реалізації слід врахувати що покупець може додати товар в рамках однієї сесії, а продовжити - у рамках іншої. Крім того, слід зобразити реалізацію цього функціоналу як для залогованих, так незареєстрованих користувачів
